One-line joke about crypto trading life, written by `main.ts` to `/output/entry.txt`:

> I bought the dip, then the dip bought a shovel, and now my portfolio chart looks like my sleep schedule: red, flat, and somehow still falling at 3am.

The joke: a trader buys the dip, the dip keeps dipping, and the portfolio chart ends up looking exactly like a ruined sleep schedule — red, flat, and somehow still falling at 3am. Setup, turn, punchline at the end, in a single line under 200 characters.

## Run

```sh
node main.ts
```

It writes the joke to `/output/entry.txt` and prints it.
